# GoonCrusher: context for AI assistants

GoonCrusher is a top-down 2D arcade car game in **Godot 4.7 / GDScript**. You drive across a procedurally generated, chunk-streamed world and run over "goons" at speed to crush them, earning coins, stars and slot-machine bonuses. Between runs, coins buy cars and per-car stat upgrades. A free demo is live on Steam (app 1941650); the current work is finishing the full release.

This file is a map. The detail lives in `docs/`:
- `docs/WORLD.md`: the 30 levels and `LevelDef`s, landscapes (`Landscape`) and regions (`Territories`), the world generator, districts, objectives and route clocks, chunk recipes and streaming, the ground shader, water, breakables, prop reactions (canopies over the car, hit reactions), wall contact, goon/AI hooks, how to add a level, landscape, region, prop or terrain.
- `docs/WORLD_ART.md`: generated world art (ground materials, strips, props and `props.json`, station, posters, the bake).
- `docs/GOONS.md`: the 43 generated goons (factions, the six classes, the `Goons` registry, verbs, crush rules, GoonFx, bake).
- `docs/PICKUPS.md`: the 79 pickups (the `Pickups` registry, drop roll, buffs, gadgets, slot paylines, pausing menus, world events, hooks in shared files).
- `docs/CAR_ART.md`: generated car art, the system damage model, the handling model (`CarHandling`, weight, the handling lab), each car's traits and the driving feel (`CarJuice`: lean, bounce, trails, engine and tyre sound).
- `docs/HUD.md` and `docs/UI.md`: the in-run HUD; the card menus, `MenuTheme` and key hints.
- `docs/AI_DRIVER.md`: the AI driver, the playtest harness and tournaments.
- `docs/PERFORMANCE.md`: the settings system, every option and preset, benchmarks and the latest numbers.
- `docs/NATIVE.md`: the C++ GDExtension (godot-cpp, building, adding a class, exporting, port candidates).
- `docs/RADIO.md`: the radio stations: what the audio author delivers (folders, format, naming, the DJ brief) and how `Radio` plays it. `docs/RADIO_SONGS.md`: the songs' lyrics, Suno style prompts, house style and ideas. `docs/RADIO_SEGMENTS.md`: the idents, talk and ads in the game, and how to write them so they generate well.
- `docs/GAMEPLAY_SUGGESTIONS.md`: the roadmap: what is done (one line each), the open work packages and questions for the author.
- `docs/TEST_SCOPE_TRANSITIONS.md`: the manual test checklist for menus, transitions and effects.

## Running and tooling

- **Engine:** Godot 4.7.2, renderer `mobile` (Vulkan). Editor: `C:/Users/Greg/Downloads/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64.exe`; use the `..._console.exe` beside it for CLI runs (it prints to stdout). The dev box (Intel HD 620, 4 threads) is the low-end target; Compatibility runs through ANGLE/D3D11 there and is slower.
- **CLI runs:** bound them with `--quit-after <frames>`. Godot eats its own display flags and saved settings override them, so use the game's user args: `-- --window=1600x900`, `-- --uncapped` (no V-Sync, no cap), `-- --safe-mode` (Potato, windowed, Compatibility, once), `-- --reset-graphics` (deletes `graphics.cfg` and `override.cfg`). F3 cycles the performance overlay.
- **Tests:** `Godot_console.exe --headless --path . -s res://tests/game/run_tests.gd` (or `scripts/*/run_game_tests.*`); the exit code is the failure count (475 tests, all passing). They use `tests/game/game_test.gd`, a small GUT-compatible base, because **GUT 9.0.0 does not parse on 4.7**. The rest of `tests/` belongs to rmsmartshape. Headless runs skip tier detection and the crashed-boot counter.
- **Benchmarks:** `scripts/debug/bench.gd` (autoload `Bench`, inert without `--bench`), e.g. `Godot_console.exe --path . -- --bench=S3 --uncapped --preset=low --seconds=90`. Scenarios and options are in its header and `docs/PERFORMANCE.md`. Output: `user://bench/`. Level scenes can also be launched directly; they fall back to the saved car.
- **Playtests:** `scripts/debug/playtest.gd` (autoload `Playtest`, inert without `--playtest`) plays real runs with the AI driver, e.g. `Godot_console.exe --headless --fixed-fps 60 --path . -- --playtest --uncapped --mode=countdown,sprint --level=prairie --car=sedan --runs=8 --seed=1`. The game, the playtest and `scripts/ai/tournament.py` all play `AIProfiles.BEST` (`"cautious"`, `scripts/ai/ai_profiles.gd`) unless `--profiles` says otherwise. `--world-preview` prints generated maps as text. Options and output: `docs/AI_DRIVER.md`. Write long output to a file.
- **Career playtests:** `-- --career --persona=rookie|grinder|explorer --start=fresh|early|mid|late|maxed --sessions=N` plays the whole game as one of three personas (`scripts/ai/personas.gd`) through the real menus (input actions and mouse clicks only): it shops, picks runs, drives them, answers every pausing screen and reads the results. It reports blocks, softlocks, menu, economy and save issues, script errors and progression milestones (`scripts/debug/career.gd`, docs/AI_DRIVER.md "Career playtests"). Scratch save; `--save=<path>` starts from a copy of any save. For hand testing, `-- --play-start=<tier>` gives a person that tier's progress on a scratch save (`--fresh` rebuilds it).
- **Never pipe a Godot run into `head` or `Select-Object -First`:** the process keeps running and spoils later benchmarks. Capture, then filter.
- **Git across machines:** `.gitattributes` pins every text file to LF (Godot writes LF everywhere; `.bat` keeps CRLF), so `core.autocrlf` no longer matters. Commit `.import` and `.uid` files: they hold import settings and resource IDs. Use the same Godot version on every machine, or each editor re-imports and rewrites the `.import` files with its own keys. `.godot/` (the import cache), `.vscode/` and Python caches are ignored.
- **Save location:** `user://` is `%APPDATA%/GoonCrusher/` (`use_custom_user_dir`). Progress `saveData_0.1.tres`; settings `settings.cfg`, `graphics.cfg`; renderer `override.cfg`. **Back them up before testing.** Bench and playtest runs use a scratch save.
- **Addons:** `gut` (tests only, broken on 4.7), `rmsmartshape` (unused, removable), `godotsteam` (loads on 4.7; no game code calls Steam yet).
- **Native code:** a C++ GDExtension in `native/` (godot-cpp 10.0.0 submodule, Godot 4.7 API, MSVC Build Tools 2022 + SCons). `scripts/windows/build_native.bat` builds debug and release into `bin/windows/` (gitignored; `bin/gooncrusher.gdextension` is tracked), so **build after cloning or making a worktree**: the game needs it (goons are `GoonBody`s) and `tests/game/test_native.gd` checks it. Native now: `GoonBody` (the goon tick's fields and movement helpers), `WorldGrid` (terrain queries and WorldHooks' grid walks), `WorldGenNative` (the build's crossings pass). Rebuild after editing `native/src/`. Details: `docs/NATIVE.md`.
- **Exports:** `export_presets.cfg` (tracked, no secrets) has one Windows Desktop preset that writes to `build/` and excludes tests, editor addons, `scripts/art/*`, bake helpers and source art. It ships whichever `bin/windows/` DLL matches the export, so **build `template_release` before a release export**. **Install the 4.7.2 export templates before shipping** (the dev box has 4.7.0).

## Architecture

### Autoloads (in load order)
| Name | File | Owns |
|---|---|---|
| `Settings` | `scripts/global/settings.gd` | `settings.cfg` (synced) and `graphics.cfg` (per machine), presets, tier detection and calibration, safe mode, the `gc_*` shader globals, the lighting hook on `node_added`, rebinding, the F3 overlay, and `menu_open` (push/pop) to block input under menus. Read with `Settings.get_value("gfx/smoke")`. |
| `Root` | `scripts/global/root.gd` | Global enums (`gameModes`, `endCondition`, `upgrade`, `terrain`), shared refs (`playerCar` (null in the menu), `carInfo`, `station`, `levelRoot`, `spawnManager`, `playerRoot`, `mainMenu`, `worldMap`), run flags and currency, `getPowerupFromWeights`, mode descriptions, `IS_DEMO`. |
| `SaveManager` | `scripts/global/saveManager.gd` | Loading, migrating and saving `PlayerData` (debounced 1 s, flushed on scene change and exit), the economy (upgrade cost `upgradePrice`: `int((lvl+1)^1.6*15)` × the car's `UPGRADE_COST_SCALE`, 1 to 2.5), selection, per-level records. |
| `Audio` | `scripts/global/Audio.tscn/.gd` | A pooled FX player (`Audio.play`), capped by Max Sound Effects, and the music: the radio, `Audio.radio` (`Radio`, docs/RADIO.md). |
| `Region` | `scripts/global/Region.gd` | The run's regions = the world map's districts: 3 goons from the level's line-up (the faction is the first's), name. Waves are one clock for the whole run (`Region.wave`: a star every 60 s, no cap, untouched by districts). Pushes the goon list to the spawner. `-- --class=` / `-- --goons=` force them. (The road atlas's six regions are `Territories`, not this.) |
| `Bench`, `Playtest` | `scripts/debug/` | Harnesses; free themselves without `--bench` / `--playtest`. |
| `Console` | `scripts/debug/dev_console.gd` | Debug builds only. Backtick toggles it. `help` lists the commands for where you are (the menu's: `start`, unlocks, coins, gems, `level`...; a run's: `heal`, `god`, `ai`, `pickup <id>`, `win`, `night`...), `help menu`/`run`/`all` the others. **`start <tier>`** (early: The Wilds done; mid: 3 regions; late: 5 regions; maxed: everything on Hard by every car; `CareerStart.TIERS`) plays from further into the game on a scratch save and `start real` goes back. **`autopilot [persona]`** hands the whole game (menus, runs, results) to a persona until any key is pressed. Other progress commands write the real save. `-- --console="start late"` runs commands at startup. |

### Flow
1. `scene/player/menu/main/main2.tscn` is the menu, built in code (docs/UI.md): GARAGE (driver cards, upgrades) and RUN SETUP (level posters, mode medallions). Mode unlocks: `Root.isModeUnlocked` (Countdown → Sprint → Marathon, the road; Goonpocalypse and Defense open once the Marathon is won on that level), `Root.MODE_AVAILABLE`, combined in `Root.isModePlayable`. `Root.MODE_PATH` is the one mode order every menu, harness and test reads. Level unlocks: the Marathon won on a level opens the next, on Medium at a region's finale (stop 5; `Root.opensNextLevel`, `openRuleText`, `openLeftText`), in `SaveManager.currentLevelPassed`, which credits the run's own level, mode and tier (`Level.runLevel`, `runMode`, `tier`). A win also credits the car (`meta.carClears`: a new car's first clear pays coins, every car clearing a mode, level and tier is a Full Garage that pays gems; `SaveManager.carClearTier`, `carsCleared`, `isFullGarage`). **Mode tiers** (`scripts/global/mode_tiers.gd`, `ModeTiers`): every mode on every level has Easy, Medium and Hard completions, picked in run setup (`PlayerData.gameTier`); the tier sets the goal and the world's toughness (`Level.tier`), pays a win bonus and a first-clear bonus, and shows as bronze, silver and gold medals. `gamemodeBeat` stays "beaten on any tier"; the level entry's `tiers` keeps the best. G opens the Goonopedia, which is also where pickups are unlocked. The menu shows cars from `CarInfo` (`scene/car/<car>/<car>_info.tres`), not car scenes.
1a. **Unlocks** (`scripts/global/unlocks.gd`, a class; docs/PICKUPS.md, "Unlocks") answers what is open for pickups, cars, levels and modes, with four states (hidden, shown, ready, open). Most pickups start locked, in one tree per kind (`start`, `parent`, `needs` in `Pickups.DATA`); locked ones never drop or get offered (`Pickups.candidates`, `openOr`, `rollOffer`). Unlocks open on the results ticket (`Unlocks.refresh`) and in the Goonopedia, never mid-run. Entry cars cost coins, advanced ones gems too. Prices are placeholders. Harnesses and tests open everything (`Unlocks.allOpen`, `--unlocks=save` to play the progression).
2. Starting a run loads the level and car on worker threads, then changes scene to `RunView.wrap(level)` (`scene/level/run_view.gd`: at Render Resolution 720p/540p the whole run renders in a SubViewport, so `get_viewport()` in a run may be that SubViewport).
3. Levels are a registry: `Levels.ORDER` (`scripts/world/levels.gd`): the road atlas's 30 levels, five stops in each of six regions (`Territories`, `scripts/world/territories.gd`: The Wilds, Tribe Country, Raider Road, Hunting Grounds, The Sprawl, The Works; each with a goon class, props, landmark and an elite strength step). The demo gets the first 10 (two regions) with Countdown, Sprint and Marathon. One `LevelDef` per level in `world/levels/<id>.tres` (`region`, `stop`, `landscape`, `lineup`, `rules`); its landscape (`world/landscapes/<id>.tres`, `Landscapes`: 15, a generator re-skinned, with a fallback skin until its art exists) supplies the world fields it leaves empty (`LevelDef.resolve`). `scene/level/levels/level_<id>.tscn` only inherits `levelRoot.tscn` and sets `def`; **edit level numbers in the `.tres`**. Tools take a level id, index or scene name (`Levels.resolve`); `-- --landscape=<id>` builds any level in another landscape.
4. `levelRoot.gd` (`Level`) applies the def, instantiates the car, attaches 5 spawners **as children of the car**, and runs day/night by tweening a `CanvasModulate` to black every 60 s. `TileManager` builds the world map on a worker and streams chunks (docs/WORLD.md).
5. Endings: everything goes through `levelRoot.endLevel()` once (`hasEnded`). The clock (`Timer.gd`) counts down except in Goonpocalypse; at 0 `Level.timeUpCondition` decides (Countdown and Defense win, Sprint and Marathon lose). Sprint wins at the station driveway, its clock derived from the A* route; Marathon is `Level.legs()` legs by tier (`Level.stationReached`); the station lot has no walls; Defense loses when the station barrier (`station.gd`) hits 0, worn down by goons that march on its pumps and blow up there (`Walker.siege`, `station.siegeStep`, `station.BLAST_DAMAGE`); Goonpocalypse is endless and beaten by surviving `ModeTiers.POCALYPSE_TARGET` × seconds, after which it escalates harder (`SpawnManager.overtime`). `gameSummary` credits `Level.runPayout(won)` = (coin + the tier's win bonus when won) × (1 + 0.1 × star, at most ×3) (`Root.computePayout`, `Root.STAR_BONUS`, `STAR_MULT_MAX`), plus a first-clear bonus and any car clear bonus, to the save and, in debug builds, appends to `user://runlog.csv`.

### Key gameplay code
- **Car:** `lib/overhead_car_2d/overhead_car_body_2d.gd`, a bicycle-model `CharacterBody2D` that handles collisions, crushing, damage, fuel, rewards, camera zoom, headlights and the station indicator. Base stats come from its `info: CarInfo` (**edit `<car>_info.tres`, not the scene**). 9 cars in `scene/car/<name>/`. Art is generated (`scripts/art/car_gen.js`, docs/CAR_ART.md): **never paint the PNGs**.
- **Handling lives in `integrate()`**, which must stay pure (one tick, no side effects): the AI driver predicts with it. It reads the ground (`World.surfaceAt`), `car.buffs`, `conditionFactor()` and `CarHandling.tune` (the numbers; docs/CAR_ART.md, "Handling"). Walls (deflect, bounce) are handled after `move_and_slide`, in `wallResponse`.
- **Input:** `scene/player/controller/playerCarController.gd`; all input is digital. When `driver` is set (an `AIDriver`), the AI holds the keys. Driving keys: W/S/A/D (or arrows), Space = Handbrake (RB), E = Fire Gadget (`UseItem`, X), Shift = Boost / Hop (`UseMove`, LB), Q = Horn (`Horn`, Y; every car, its own sound), F = the car's Ability (`Ability`, B; only the semi's Drop the Load so far).
- **Car traits** (`CarTraits`, `CarTraitRig`; docs/CAR_ART.md "Traits"): two signature features per car in its `CarInfo.traits`, shown as badges on the garage card and under Signature in the Goonopedia. Handling traits are flags read inside `integrate()`; rules live in the car's `CarTraitRig`.
- **The semi's trailer** (`CarTrailer`, docs/CAR_ART.md "Trailer"): its own body on a fifth wheel, moved by the car after each physics tick, outside `integrate()`; baked from `car_gen.js`'s `semiTrailer` with the semi.
- **Handbrake:** `CarInput.handbrake`, inside `integrate()` (`HANDBRAKE_*` constants): above 150 px/s the rear lets go for a powerslide that catches at 70°; steering, engine, traction and weight shape it per car. The AI driver never pulls it, but its predictions run the same `integrate()`. Holding a slide charges a **drift boost** fired on release (`DRIFT_TIERS`, `tickDriftCharge`, outside `integrate()`). The physics shapes are only the bumpers, so the flanks and tail crush in `slamGoons()` (a drift swats goons with the back of the car; docs/GOONS.md, "Crush feel").
- **Goons** (docs/GOONS.md): tune in `scripts/global/goons.gd`; base `Walker` (`scene/enemy/walker/walker.gd`, on the native `GoonBody`, which holds the per-tick fields and movement helpers), verbs in `goon_verbs.gd`, effects in `goon_fx.gd`. The car calls `goon.tryCrush(car, speed)`. The AI reads `Walker.mode` and `myMode`; keep those names. Capped at 250 (`SpawnManager.GOON_CAP`), swept every 0.5 s when off screen and either over 8000 px away or stuck (`Walker.isStuck`).
- **Pickups** (docs/PICKUPS.md): tune in `scripts/global/pickups.gd`. Collecting credits at once; the flying icon is visual only. **Never credit rewards from an animation.** A new pickup needs a `parent` in its kind's tree; any code that hands out a fixed pickup id goes through `Pickups.openOr` (or `PickupEffects.collect`, which does).
- **Prize games:** the Claw Crane, Slot Machine (`scene/player/slots/slot_machine.gd`), Prize Wheel, The Deal, The Vault and Pit Shop all extend `PickupMenu` (`scene/pickups/menus/`), one frame of one size that skids in under a hatch shutter (`GameHatch`), credits prizes as they are won (`award`) and ends on a winnings board that says what each prize did; no game pays another (`Pickups.NOT_IN_GAMES`). Try one in the prize lab: `tests/prize_lab/<game>.tscn`, F6 (docs/PICKUPS.md, "Prize games"). Crushes earn crush XP toward **gift boxes** (`CrushPrizes`, `GiftBox`, `playerRoot.checkGiftBox`; box *n* needs `50 n²` XP), each holding one unlocked prize game (Claw, Scratch, Wheel, Deal, Slot, Vault; only the Claw starts open); higher tiers play better versions (docs/PICKUPS.md, "Gift boxes"). `-- --prize=<game>` forces the game. Pausing pickup menus join group `slotMachine` so the harnesses tap through them.
- **HUD:** `scene/player/playerRoot.tscn` (docs/HUD.md). Pickups fly to the node in group `"<powerup>ui"`.
- **Menus:** give a new menu `theme = MenuTheme.theme()`, one `PrimaryButton`, and `KeyHint`s; never hard-code "A" or "Enter" (docs/UI.md). Everything must work with the mouse alone (clickable `KeyHint.bar`s; children of a clickable row ignore the mouse). Show amounts with the game's symbols, not words ("1,500 (coin)", not "1,500 coins"): `MenuTheme.symbolRow`, `costParts` and `setButtonParts` (docs/UI.md, "Symbols").
- **Transitions:** screen changes go behind the garage shutter (`Transition.play(swap)`, `scene/ui/transitions/`); in-run games use `GameHatch`, overlays `Juice.dropIn`. Headless and the harnesses skip them (`Transition.instant()`); Reduce Motion fades. Never credit rewards from a transition (docs/UI.md, "Transitions").
- **Music** is the radio (docs/RADIO.md): tracks are files in `sound/radio/<station>/`, scanned at startup, so adding music needs no code. Never add another music player; anything that should duck the music plays on the Voice bus.
- **Settings:** to add one, add the key to `Settings.DEFAULTS` (plus `OPTIONS`/`RANGES`, and `PRESET` if presets drive it), apply it in `Settings.applyKey` or where it is read, then add a row in `settings_menu.gd`'s `buildSchema()`.

### Save data (`scene/player/save/playerData.gd`)
- A text `.tres` that embeds the script path: **renaming or moving `playerData.gd` breaks player saves.**
- `SaveManager.migrate()` merges every save with the defaults. Bump `SAVE_VERSION` (now 8) and extend `migrate()` when adding fields; `tests/game/test_save_migration.gd` covers it.
- **Saves older than version 8 (before the road atlas) start over** (`SaveManager.FIRST_KEPT_VERSION`, the author's call): `load_data` copies the old file to `saveData_0.1.v<version>.tres` and makes a new save. That includes demo saves from before then. Any run of the game or the tests with this code does this to the real save in `user://`, so back it up (or point a worktree at its own user dir with a local `override.cfg`: `[application] config/custom_user_dir_name="..."`).
- `levels` is rebuilt from `Levels.defaultEntries` keeping only each entry's unlock and `gamemodeBeat`; put anything else per level in `meta`.
- `meta` sections: `records` (keyed by level id, `SaveManager.levelKey`), `hints`, `lifetime` (unlock counters), `medals`, `achievements`, `pickups` (discovered), `unlocks` (opened ids), `carClears` (level id → mode → car → best tier).
- `settings` in the save is legacy (read once by `Settings.import_legacy_volume()`); delete it one release after launch.

## Conventions and gotchas

- **Physics is tick-based.** Steering ramp, fuel burn, zoom, buffs and goon counters advance per physics tick. Never change `physics_ticks_per_second` or expose it. Anything visual must be delta-based or per tick, because frame caps exist (slot reels step in `_physics_process`).
- **One 3D text shader:** every 3D-text material references `shader/3dtext.gdshader` (`time_mode` 0–3); never inline it. Every `gc_*` global a shader uses must be declared in `project.godot [shader_globals]`.
- **Icons** are original SVGs in `texture/icon/`: `<name>.svg` for plain sprites, `<name>_flat.svg` for anything the 3D text shader draws (else the depth doubles). Pickup icons come from `scripts/art/pickup_icons.js`. `discord.png`/`steam.png` must be the official brand files.
- **Generated art** (cars, goons, pickups, world): change the generator and re-bake; never edit baked files.
- **Night is gameplay.** At night only the car's lights show the world: 5 shadowed headlamps or the baked `simpleCone` (re-bake with `scripts/debug/bake_headlight_cone.gd` if the lamps change). Goons, tall props and walls carry `LightOccluder2D` (world ones tagged `gc_world`). `Settings.onNodeAdded` ANDs the Lighting setting with each light's authored state; only Lighting Low (Potato) changes what the player can see.
- **Physics layers:** 1 "Player" = world (chunk walls, props, station) and the car body; 2 "CarBody" = `carBodyArea`; 3 "Goon" = goons only (`collision_layer = 4`, mask 1+2), so goons never collide with each other. The car's mask is 1+3. There is no water collision: deep water is a grid check (`World.lethalAt`). Anything that must touch goons needs layer 3.
- **Walls:** `World.isWall(collider)` (`is StaticBody2D or is TileMap`, mirrored in `GoonBody::advance`); any `CharacterBody2D` is treated as a goon. Wall damage is per contact (`wallTick`); breakables smash at speed (docs/WORLD.md).
- **Terrain** is described once, in `World.TERRAIN`; `Root.terrain` is append-only and mirrored (docs/WORLD.md, "How to add a terrain value"). Use `World.isPassable/isLethal/...`, never compare against WATER or HILLS. `World`'s runtime queries are called from `integrate()` and must stay allocation-free; with a real map they answer from its native `WorldGrid`, so a change to a query's rule goes in both the GDScript and `native/src/world_grid.cpp` (the parity tests compare them).
- **World workers** (`WorldGen`, `WorldField`, `ChunkRecipe`) touch only their job Dictionary: no nodes, autoloads or global RNG (use `WorldGen.ihash`). Never build a raster or recipe on the main thread in a run; keep `ChunkView` steps inside `TileManager.APPLY_BUDGET_USEC`.
- **Explosions:** `Root.levelRoot.explode(pos)` (pooled); never instantiate `explosionScene` per blast.
- **Stats:** `clover` is labelled "Clover" (drop chance), `luck` "Dice" (prize quality). Upgrades cap at `SaveManager.MAX_UPGRADE_LEVEL` (20), in-run stats at `STAT_CAP` (150). Oil goes through `fuelBurn()`, armor once inside `damage()`. Engine, steering, traction and **weight** (`CarInfo.weight`, 0–100, never upgraded) become handling in `CarHandling` (docs/CAR_ART.md, "Handling"); tune it there, live with the console's `handling` command, and check it with `scripts/debug/handling_lab.gd`.
- Goon animations are one PNG per frame (an atlas was measured and dropped). Pickup materials are shared; don't set `resource_local_to_scene` on them.
- `randi() % n - 1` indexing in `Region.gd` and `gameSummary.gd` looks wrong but works (index -1 wraps).
- **Style:** tabs, camelCase (some snake_case), `Root.*` globals, `$Node` paths. No empty `_process`/`_ready` stubs. Connect autoload signals (e.g. `Settings.changed`) to methods, not lambdas.

## Known issues
- Nothing has been tuned by hand: Sprint clocks, the drop mix, the 9 cars, the modes' numbers, late-level escalation and payouts (`docs/GAMEPLAY_SUGGESTIONS.md`, package 1 and "Open items").
- Night crowds miss the Low/Potato frame targets (S4 Low 54–56 fps avg, 1% low 19–25): the native goon tick halved goon script, but above 160 goons physics is still 10–12 ms, mostly the physics server (`docs/PERFORMANCE.md`).
- The AI driver has no real Defense strategy and skips pickups near deep water (`docs/AI_DRIVER.md`).
- World follow-ups (cars stalling on bumper-only collision, highway edges no first-run hints, a 0.8–1.3 s world build that is still mostly GDScript): `docs/WORLD.md`, "Known issues".
